## P1 Violations — Deterministic Dependency Resolution

### P1-001: package-lock.json NOT committed (CRITICAL)

`package-lock.json` is listed in `.gitignore` and is NOT tracked by git.

**Impact:** Every `npm install` on a fresh clone resolves dependencies from scratch. Transitive dependency resolution is NOT deterministic — different `node_modules` trees can emerge across developer machines, CI runners, and deployment environments. This is the single most impactful reproducibility gap.

**Evidence:**
- `git ls-files package-lock.json` → empty (not tracked)
- `git check-ignore package-lock.json` → confirms gitignored

**Severity:** P1 — Blocks deterministic builds entirely.

## P4 Issues — Explicit Config

### CONFIG-002: `minify` not explicitly set in build config

Vite defaults to `"esbuild"` minification. While this is the recommended default, the invariant requires every critical option to be explicitly set rather than relying on defaults.

   - This is the single most impactful fix. Add `!/package-lock.json` to `.gitignore` to unignore it, or remove the `/package-lock.json` entry entirely.

