**Finding: README-ARCH-001** | Minor

- Location: README.md — Quick Start Step 2, `UserRepo` definition; Step 3, `settingsRepo` definition
- Issue: Both examples use `ServerResponse<T>` as a return type annotation but `ServerResponse` is not included in the import statement. `import { getApiService, useDataState, AppStateHandler } from "astra"` omits `ServerResponse`. A developer copying this example gets a TypeScript error.
- Evidence: `feature/repository.md` — `ServerResponse` is a public export; `api-surface.md` confirms it in the entry point
