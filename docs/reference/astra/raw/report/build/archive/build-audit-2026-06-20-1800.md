### Finding ID
BUILD-006

### File
`dist/` (generated by `vite-plugin-dts`)

### Category
Type Generation

### Invariant Violated
`docs/raw/architecture/invariants/deterministic-build.md`

### Severity
P2

### Violation Type
Test `.d.ts` files present in stale dist; root cause of dts glob resolution not yet verified on fresh build

### Evidence
Files present in stale dist:
```
dist/publicExports.test.d.ts
dist/common/repo/ApiService.test.d.ts
dist/common/repo/HttpStatusCode.test.d.ts
dist/common/hooks/useDataState.test.d.ts
dist/common/components/organisms/AppStateHandler.test.d.ts
```
Config carries `exclude: ["**/*.test.ts", "**/*.test.tsx", ...]` in both `tsconfig.app.json` and `vite-plugin-dts`. These patterns were present in the previous config and did not prevent test file generation. The underlying resolution behavior is unchanged for glob patterns.

### Invariant Rule Violated
`deterministic-build.md` §Architectural Rule: build artifacts must match documented scope

### Recommendation
Run `npm run build` and inspect new dist. If test `.d.ts` files persist, add a post-build cleanup:
```json
"build": "vite build && node -e \"const g=require('fs').globSync('dist/**/*.test.d.ts',{recursive:true});g.forEach(f=>require('fs').unlinkSync(f))\""
```
Or use `rimraf dist/**/*.test.d.ts` as a postbuild step.

### Impact
Published package contains test artifact stubs. Minor consumer confusion; no functional breakage.
