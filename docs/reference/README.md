# Architecture and design references

These documents are maintained in this repository to guide Vyasa UI's architecture and design. They remain available independently of other repositories.

- [Astra documentation](astra/raw/architecture/core/feature-structure.md): feature organization, MVVM, repositories, state and Electron integration.
- [Prati documentation](prati/raw/architecture/runtime-maps/provider-hierarchy.md): components, design system, theming, localization, and provider hierarchy.
- Vyasa's original knowledge bundle [index](vyasa/knowledge-index.md), [log](vyasa/knowledge-log.md), and [profile](vyasa/knowledge-profile.json) are preserved here. The knowledge sections live under `knowledge/` and the requirements under `docs/requirements/`.

Vyasa UI uses both libraries. Verify the installed package versions and public exports before implementation; do not assume every reference describes the exact installed version.
