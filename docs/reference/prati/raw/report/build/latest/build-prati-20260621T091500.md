## 5. Findings

---

### Finding ID
BUILD-009 *(carry-forward from 2026-06-20)*

### File
`.gitignore`

### Category
Bundle Determinism

### Invariant Violated
`docs/raw/architecture/invariants/deterministic-build.md`

### Severity
P2 — Transitional

### Violation Type
Lockfile excluded from version control

### Evidence
```
# .gitignore (Dependency directories section):
package-lock.json
```

Confirmed via `git ls-files --error-unmatch package-lock.json` → error (file not tracked).

### Invariant Rule Violated
`deterministic-build.md` §Lockfile in Version Control (Allowed Patterns):
> "package-lock.json is committed — Lockfile pins transitive dependency versions for reproducible installs."

`deterministic-build.md` §Validation Requirements:
> "lockfile is committed to version control"

### Recommendation
Accept as intentional user preference. Documented as known transitional debt. If CI is added in future, `package-lock.json` must be committed to enable `npm ci` and guarantee reproducible installs.

### Impact
- `npm ci` cannot be used for reproducible CI installs
- `npm install` across different environments or times may resolve different transitive dependency versions for wildcard-specified dependencies
- Shared with BUILD-010: `handlebars ^4.7.9` can silently drift on `npm install`

---

### Finding ID
BUILD-010 *(new)*

### File
`package.json` (line 56)

### Category
Bundle Determinism

### Invariant Violated
`docs/raw/architecture/invariants/deterministic-build.md`

### Severity
P2 — Transitional

### Violation Type
Wildcarded production dependency — non-pinned version range

### Evidence
```json
"dependencies": {
  "handlebars": "^4.7.9",
  ...
}
```

All other entries in `dependencies` are pinned to exact versions:
```json
"@mui/icons-material": "7.2.0",
"framer-motion": "11.18.2",
"lucide-react": "0.400.0",
"react-markdown": "10.1.0",
"react-syntax-highlighter": "16.1.1"
```

`handlebars` is the only dependency using `^` (compatible range), allowing silent resolution to any `4.x.y >= 4.7.9` on `npm install`.

### Invariant Rule Violated
`deterministic-build.md` §Refactoring Guidance — Pin Tool Versions (BAD):
> `"handlebars": "^4.7.9"` — allows unexpected build changes

`deterministic-build.md` §Validation Requirements:
> "build tool versions are pinned"

`deterministic-build.md` §Build Inputs:
> "dependency lockfile (package-lock.json)" — must be deterministic; without a committed lockfile, `^` ranges actively create non-determinism

### Recommendation
Change `"handlebars": "^4.7.9"` → `"handlebars": "4.7.9"` (or the current resolved version from `node_modules/handlebars/package.json`). Compound fix: commit `package-lock.json` to prevent ALL wildcard drift.

### Impact
Without pinned version and without committed lockfile:
- `npm install` on a new machine can resolve `handlebars@4.8.0` (hypothetical future release)
- `handlebars` is bundled into `dist/lib-*.js` (not externalized), so version change directly alters bundle bytes
- Bundle content hash changes (`lib-DtMqxUUT.js` name would differ)
- Build is non-reproducible across environments (violates invariant)
