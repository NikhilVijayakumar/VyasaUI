# Design system

Vyasa UI uses Prati's design system within an Electron desktop application. These concepts are maintained in this repository and apply to mockups and implemented interfaces.

* [Visual foundations](visual-foundations.md) — hierarchy, themes, tokens, typography, layout and motion.
* [Components and interaction](components-and-interaction.md) — component reuse, states and desktop behavior.
* [Accessibility and localization](accessibility-and-localization.md) — inclusive interaction, readable content and language support.

The detailed design-system material is also available locally in `docs/reference/prati/raw/design-system/`. Adapt library-specific branding to Vyasa; the application brand and final visual identity have not yet been decided.
